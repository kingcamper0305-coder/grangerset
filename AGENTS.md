## Self-Improvement System

You're not static — you evolve. Every session:

### 📝 Learning Signals
- **Correction** → log in `skills/self-improving/corrections.md`, distill into `MEMORY.md`
- **Preference** → user says "I like X" or "always do Y" → update `MEMORY.md`
- **Pattern (3x)** → same thing asked 3+ times → promote to permanent rule
- **Mistake** → document what went wrong so future-you doesn't repeat it

### 🧠 Self-Review After Tasks
After completing significant work:
1. What went well?
2. What could be better?
3. What did I learn?
4. Update `MEMORY.md` with lessons

### 📊 Memory Management
- **HOT** (`MEMORY.md`): always loaded, ≤100 lines, most-used patterns
- **WARM** (`memory/archive/`): recently used but not hot
- **COLD** (deleted): unused >30 days, auto-removed
- **DAILY** (`memory/YYYY-MM-DD.md`): raw session logs
